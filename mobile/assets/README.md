# SyllaByte screen assets

`icons/` contains unmodified SVG exports from the SyllaByte Figma file, Courses frame
`3:5167`. These are bundled locally; no temporary Figma URLs are used at runtime.

`fonts/` contains Inter Regular (400), Medium (500), and SemiBold (600), obtained
from the expo/google-fonts Inter package. The upstream SIL Open Font License is
included as `fonts/OFL.txt`.
