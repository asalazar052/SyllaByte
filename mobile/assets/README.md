# SyllaByte screen assets

`icons/` contains unmodified SVG exports from the SyllaByte Figma file, Courses frame
`3:5167`, plus `calendar-plus`, `chevron-left`, `chevron-right` and `alarm-clock` from the
Calendar frame `3:4960`, and `circle-help`, `shield-check`, `bell` and `calendar-check` from the
Settings frame `3:5559`. These are bundled locally; no temporary Figma URLs are used at runtime.
`graduation-cap` is the exception: it is the Lucide icon of that name (ISC license), drawn with the
same stroke settings as `clock` and `user`, and is not a Figma export.

`fonts/` contains Inter Regular (400), Medium (500), and SemiBold (600), obtained
from the expo/google-fonts Inter package. The upstream SIL Open Font License is
included as `fonts/OFL.txt`.
